# 大 QMT 隔夜涨停买入模型

此目录存放与大单策略分开的 QMT 原生 Python 隔夜下单模型。

- `QMT_OVERNIGHT_LIMIT_UP_BUY.py`：独立原生模型，默认实盘开启，账户为 `32011276`。
- `docs/DESIGN.md`：运行时序、校验、安全状态和部署说明。
- `PLAN_TRADE_DATE` / `ORDER_PLAN`：入口内存中的交易日、股票代码和计划金额。
- `tests/`：离线接口与时序验证。

实盘默认启用，账户为 `32011276`。每日修改入口中的交易日和计划后再编译；默认空计划会停止初始化。模型不依赖 CSV、JSON 状态文件、qmtmini、xtdata 或外部 Python 进程。

模型应在 08:30 前启动，并立即分片读取涨停价、计算股数和金额；只接受 `TradingDay` 与当日计划日期一致的 `UpStopPrice`，日期或价格字段尚未就绪时每 500ms 重试。价格预检须在 08:29:58 前完成；之后复核资金、保留批次并预生成首轮委托参数，到 08:30 后在一次调度回调中连续提交整批委托（最多 500 笔）。若价格预检错过 08:29:58，或准备工作跨过 08:30，整批停止；08:30 后才启动也会停止，不会延迟补单或使用前一交易日价格。QMT `[quote]` 是仿真模式，不会代表真实委托；发送实盘订单时必须使用 `[trade]` 模式。

实盘启动会使用 QMT `get_trade_detail_data(..., "order")` 检查已有委托。查询失败、任一记录没有策略身份，或发现本策略委托时会停止。代码扫描查询返回的全部记录，不按日期过滤；须先在本机 QMT 核实查询是否仅含当日记录、策略名字段是否可用。模型不保存跨重启状态，也不恢复上次运行的重试次数。
