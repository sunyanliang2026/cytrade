# 变更记录

## 2026-10-21（L2 原始时间字段收敛）

- L2 JSONL 落盘保留 `received_time`、`event_time` 和 `latency_ms`；前两者统一格式为 `HH:MM:SS.mmm`。
- `event_time` 优先使用带毫秒的 QMT `time`，缺失时回退 `stime`；移除 `received_at`、`event_time_raw`、`latency_time_raw` 等辅助时间字段，原始行情仍保存在 `data`。
- 新增落盘字段格式和事件时间回退测试。

## 2026-10-21（首封大单增加开盘低点过滤）

- 首封单笔涨停价大单立即下单路径增加 `day_low < open_price * 0.985` 条件，与累计首封共用同一低点判断。
- 低点条件使用已缓存状态：盘中启动由初始快照预填，盘前启动后由连续竞价 `l2quote` 更新；合格 `l2order` 回调即时判断并触发首封单笔大单，不等待下一轮报价；回封大单路径不变。
- 增加严格边界、盘中快照预填及首笔 L2 大单立即触发的回归测试。

## 2026-10-21（大单策略取消 tick 实时订阅）

- 大单模型实时订阅改为 `l2quote`、`l2order`；启动时的 `get_full_tick` 快照仍保留，不影响盘中初始状态判断。
- 负涨幅退出改由连续竞价 `l2quote.lastPrice < last_close` 触发；行情延时超过 1000ms 时仍忽略该信号。触发后只取消该股的 `l2quote`、`l2order` 订阅，不撤销已有委托。
- 移除 tick/l2quote 涨停首报比较和普通 tick 计数，阈值日志及周期汇总按剩余两个订阅周期输出。
- 本地已存 `l2quote` 数据的字段检查确认 `lastPrice`、`lastClose` 可用于负涨幅判断；本次不改账户、下单参数、买入阈值或撤单逻辑。
- 本机 QMT Python 环境运行大单策略离线测试 40 项全部通过；入口已覆盖同步到 QMT Python 目录，源文件与部署副本 SHA-256 一致。实盘回调仍需在交易时段观察。
